# MernProject
    M: MongoDB (DB)
    E: ExpressJs (Backend)
    R: ReactJs (Frontend)
    N: NodeJs (Backend)

## Frontend (Browser / Client side)
    React APP


    >> Commands
        > npx create-react-app frontend
        > npm i react-router-dom
        > Run: npm start
        > npm i date-fns --save



## Backend (Server)
    ExpressJs+NodeJs

    >> Commands
        > npm init -y
        > npm i express
        > npm i -g nodemon
        > Run: nodemon server.js
        > npm i dotenv
        > npm i mongoose
        > npm i bcrypt(encrypt passwords)
        > npm i validator(email validation)

        
## API - Endpoints:
    GET     /workouts       -->Get all the workout docs
    POST    /workouts       -->Create a new workout doc
    GET     /workouts/:id   -->Get a single workout doc
    Delete  /workouts/:id   -->Deletes a single workout doc
    PATCH   /workouts/:id   -->updates a single workout
